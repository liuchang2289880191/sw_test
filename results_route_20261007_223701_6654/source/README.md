# RMA 路径可辨识性补充实验

这是独立套件；不修改原 benchmark、rma_supplement 或已有硬件结果。

目标：打破原 quick 实验中 XY 去程／YX 回程等特征的重合，让 14 列候选模型能够分别估计。满秩只说明线性模型参数可辨识，不证明实际路由为 XY 或 YX。

## 在服务器运行

解压 `rma_route_identify_20261007.zip`，进入新目录：

```bash
cd rma_route_identify
TOPO_DIAG_ONLY=1 bash run_route_identify.sh q_share
bash run_route_identify.sh q_share
```

第一条执行四项新背景核对的接口／正确性诊断；每项返回 `TOPO_RETURN`，最后显示完成路径后，再运行第二条。第二条默认五作业，每作业 256 项、每项 2048 个测量 RTT。可用 `TOPO_REPEATS=1` 做一次正式试跑，再另开新结果目录运行五次。登录节点需要 Python 3 标准库、swgcc/1473 和 bsub，不需要 NumPy。

只预览计划、不提交：

```bash
python3 generate_plan.py --out preview --seed 20261008
```

## 具体布局

- 探针仍为 CPE 0→54 和 54→0，即几何块 0↔15 的 A 核。
- 每个方向保留原 quick 的六个背景位置作为新作业中的对照，同时增加十个跨行、跨列背景布局。
- 共 32 个几何布局，每布局测 8 B 与 1 KiB 探针，共 64 个配对组。每组以 ABBA 或 BAAB 测两次无背景、两次带背景，共 256 项／作业。
- 回信均为 8 B；背景均为 4 KiB、W=4。背景端点不占探针端点块。控制和处理都采用同一 ping-pong 内核。
- `layouts.json` 固定几何布局，种子只改变组顺序和 ABBA／BAAB。布局选择只用候选几何信息，未使用已有干扰结果的强弱做选择。
- `plans/preview/route_features.csv` 列出每条背景流的 XY、YX 候选路径以及全部 12 个重叠特征。

相邻背景流在 XY／YX 下路径相同；跨行、跨列背景流才让这两个假设给出不同背景路径。例如块 1→6：XY 为 1→2→6；YX 为 1→5→6。实际选择列表以 layouts.json 为准。

## 上机前的数学验收

`generate_plan.py` 在写计划前，用有理数消元计算精确秩，并计算列范数归一化后的条件数。全体配置及两个探针方向分别要求 14／14，条件数小于 100，否则拒绝计划。当前联合矩阵条件数约 27.18，两方向分别约 27.28；预览的 `design_audit.json` 保存具体数值。

离线选择程序 `select_layouts.py` 仅在工作站上使用 NumPy；服务器不运行它。满秩后仍可能参数敏感，分析必须同时看条件数、分组预测误差和作业间稳定性。

## 内核与计时

主／从核和共用头文件逐字复制自已成功运行的 `results_20261007_211507_31272/source/`，哈希在 `KERNEL_PROVENANCE.json`。因此沿用 per-source ready、stop 回答字、最终精确次数元数据、数据校验、带超时等待与每项 60 秒主核超时，不在登录节点执行目标二进制。

本次增加的是几何背景配置，不是更换测量协议。新内核软件开销仍存在；报告的 RTT 是接口、序号处理、等待、对端响应和回信的协议成本。与旧 benchmark 的约 200 cycles RTT 不可直接拼接；本套件未校准或扣除软件开销。原始历史锚点结果只作参考，正式比较以新作业内配对为准。

每个背景源首批本地完成后发送 ready；探针收到 ready 后预热四次再计时。背景持续发起直到计时后收到 stop；接收端按实际次数排空。背景平均速率与探针干扰会共同变化，不代表等注入强度。

## 自动分析输出

全部文件、发送／接收次数、错误／超时／上限命中、计时公式及计划一致性均通过后才分析。处理／控制大于 1 表示 RTT 增长。

`analysis/` 保存：

- `paired_effects.csv`：作业内配对比值与控制漂移；`route_summary.csv`：五作业中位数／范围及背景速率。
- `background_load.csv`、`batch_samples.csv`：实际背景速率与连续 64 RTT 的批均值；不是单消息 p95／p99。
- `candidate_models.csv`：常数＋大小、XY、YX、14 列联合描述模型的秩、条件数与留出误差。
- `candidate_coefficients.csv` 与 `candidate_predictions.csv`：描述性系数／预测；不能称为实测物理端口成本。
- `design_audit.json`、`raw_audit.csv`：实际计划可辨识性与原始文件哈希。

留出同一有向背景核对时，把其两个探针方向及两种消息大小放在同一折；另外留出整个探针方向。训练折不满秩时明确拒绝该折，不用伪逆隐藏问题。范围不是置信区间；五次同节点作业不是跨节点验证。

本地协议模拟只验证控制、数据和输出格式，不模拟片上物理路由；真实性能需以上述服务器新诊断和正式运行结果为准。
